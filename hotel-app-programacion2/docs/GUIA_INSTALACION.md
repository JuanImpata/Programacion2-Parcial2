# Guía Paso a Paso de Instalación - Hotel App\n\n## Requisitos del Sistema\n\nAntes de comenzar, verifica que tengas instalado:\n\n### Windows, macOS, o Linux\n\n**1. Node.js v18+**\n```bash\n# Verificar versión\nnode --version\n\n# Si no está instalado, descarga desde: https://nodejs.org/\n```\n\n**2. MySQL v8+**\n```bash\n# Verificar versión (si está instalado)\nmysql --version\n\n# Descargar desde: https://dev.mysql.com/downloads/mysql/\n# O usar MySQL Community Server\n```\n\n**3. Git**\n```bash\n# Verificar versión\ngit --version\n\n# Descargar desde: https://git-scm.com/\n```\n\n**4. npm (viene con Node.js)**\n```bash\n# Verificar versión\nnpm --version\n```\n\n---\n\n## Paso 1: Clonar el Repositorio\n\n### Opción A: Usando Git\n```bash\n# Abre terminal/PowerShell en la carpeta donde quieras el proyecto\n\ncd Downloads  # O la carpeta que prefieras\n\ngit clone https://github.com/tuusuario/hotel-app-programacion2.git\n\ncd hotel-app-programacion2\n```\n\n### Opción B: Descargar ZIP\n1. Ve a: https://github.com/tuusuario/hotel-app-programacion2\n2. Haz clic en \"Code\" → \"Download ZIP\"\n3. Extrae el ZIP en la ubicación deseada\n4. Abre terminal en esa carpeta\n\n---\n\n## Paso 2: Configurar la Base de Datos\n\n### 2.1 Abrir MySQL\n\n#### En Windows (Command Prompt):\n```bash\nmysql -u root -p\n# Se pedirá contraseña\n```\n\n#### En macOS (Terminal):\n```bash\nmysql -u root -p\n```\n\n#### En Linux (Terminal):\n```bash\nsudo mysql -u root -p\n# Se pedirá contraseña del sistema\n```\n\n### 2.2 Crear Base de Datos y Tablas\n\n**Opción A: Desde línea de comandos (recomendado)**\n```bash\n# En la terminal (NO dentro de MySQL):\n\nmysql -u root -p < database/schema.sql\nmysql -u root -p hotel_app_db < database/seeds.sql\n\n# Te pedirá la contraseña de MySQL dos veces\n```\n\n**Opción B: Manualmente desde MySQL**\n```bash\n# Dentro de MySQL (mysql> prompt):\n\nsource database/schema.sql;\nsource database/seeds.sql;\nexit;\n```\n\n### 2.3 Verificar Base de Datos\n```bash\n# Conéctate a MySQL:\nmysql -u root -p\n\n# Dentro de MySQL:\nSHOW DATABASES;\nUSE hotel_app_db;\nSHOW TABLES;\nSELECT * FROM usuarios;\n# Deberías ver 5 usuarios de prueba\nexit;\n```\n\n---\n\n## Paso 3: Configurar el Backend\n\n### 3.1 Instalar Dependencias\n```bash\n# En la terminal, en la carpeta del proyecto:\n\ncd backend\n\nnpm install\n\n# Esto descargará e instalará todas las dependencias\n# Toma 1-2 minutos\n```\n\n### 3.2 Configurar Variables de Entorno\n```bash\n# Copiar archivo de ejemplo:\n\ncp .env.example .env\n\n# O si estás en Windows PowerShell:\nCopy-Item .env.example .env\n```\n\n### 3.3 Editar el Archivo .env\n\nAbre `backend/.env` con un editor de texto (VS Code, Notepad, etc.):\n\n```\nDB_HOST=localhost\nDB_USER=root\nDB_PASSWORD=tu_contrasena_mysql\nDB_NAME=hotel_app_db\nJWT_SECRET=secreto_super_seguro_programacion2\nPORT=3001\n```\n\n**Nota:** Reemplaza `tu_contrasena_mysql` con la contraseña que usaste para MySQL.\n\n### 3.4 Iniciar el Backend\n```bash\n# Aún en la carpeta backend:\n\nnpm run dev\n\n# Deberías ver:\n# > nodemon server.js\n# Servidor corriendo en http://localhost:3001\n```\n\n**Deja esta terminal abierta. El servidor debe seguir corriendo.**\n\n---\n\n## Paso 4: Configurar el Frontend\n\n### 4.1 Abrir Nueva Terminal\n\n**En la misma carpeta del proyecto, abre una NUEVA terminal:**\n- Windows: Clic derecho → \"Abrir terminal en PowerShell\"\n- macOS/Linux: Nuevo tab o ventana de terminal\n\n### 4.2 Instalar Dependencias\n```bash\n# En la nueva terminal:\n\ncd frontend\n\nnpm install\n\n# Toma 1-2 minutos\n```\n\n### 4.3 Verificar o Crear .env\n\nVerifica que exista `frontend/.env`:\n```\nVITE_API_URL=http://localhost:3001/api\n```\n\nSi no existe, créalo con este contenido.\n\n### 4.4 Iniciar el Frontend\n```bash\n# Aún en la carpeta frontend:\n\nnpm run dev\n\n# Deberías ver:\n# ➜  Local:   http://localhost:5173/\n```\n\n**Deja esta terminal abierta también.**\n\n---\n\n## Paso 5: Verificar que Todo Funciona\n\n### 5.1 Acceder a la Aplicación\n\n1. Abre tu navegador (Chrome, Firefox, Safari, etc.)\n2. Ve a: **http://localhost:5173**\n3. Deberías ver la pantalla de login\n\n### 5.2 Iniciar Sesión\n\nUsa estas credenciales:\n- **Usuario:** admin\n- **Contraseña:** Admin123$\n\n### 5.3 Dashboard\n\nSi ves el Dashboard con:\n- Tu nombre (admin)\n- Tu rol (admin) en amarillo\n- Tarjetas con números de hoteles, reservas, reservantes\n\n✅ **¡La instalación fue exitosa!**\n\n---\n\n## Paso 6: Detener la Aplicación\n\n### Para detener sin perder los datos:\n\n**En cada terminal, presiona:**\n```\nCtrl + C\n```\n\nLas bases de datos se mantienen en MySQL.\n\n---\n\n## Solución de Problemas Comunes\n\n### Error: \"Port 3001 is already in use\"\n**Problema:** Otro proceso está usando el puerto 3001\n**Solución:**\n```bash\n# Busca y mata el proceso (Linux/macOS):\nlsof -i :3001\nkill -9 <PID>\n\n# O en Windows:\nnetstat -ano | findstr :3001\ntaskkill /PID <PID> /F\n```\n\n### Error: \"ECONNREFUSED\" en el login\n**Problema:** El backend no está corriendo\n**Solución:** Verifica que tengas abierta la terminal con `npm run dev` en la carpeta backend\n\n### Error: \"Access denied for user 'root'@'localhost'\"\n**Problema:** Contraseña de MySQL incorrecta en .env\n**Solución:** \n1. Verifica tu contraseña de MySQL\n2. Actualiza el archivo `backend/.env`\n3. Reinicia el backend\n\n### Error: \"Cannot find module 'bcrypt'\"\n**Problema:** Las dependencias no se instalaron correctamente\n**Solución:**\n```bash\ncd backend\nrm -rf node_modules package-lock.json\nnpm install\n```\n\n### Error: \"Database 'hotel_app_db' doesn't exist\"\n**Problema:** No se ejecutó el script schema.sql\n**Solución:** Ejecuta nuevamente:\n```bash\nmysql -u root -p < database/schema.sql\n```\n\n### Página en blanco en http://localhost:5173\n**Problema:** Webpack/Vite aún está compilando o hay error\n**Solución:**\n1. Espera 30 segundos\n2. Recarga (F5)\n3. Abre la consola del navegador (F12) para ver errores\n4. Verifica que el backend esté corriendo\n\n---\n\n## Estructura de Carpetas Después de la Instalación\n\n```\nhotel-app-programacion2/\n├── backend/\n│   ├── node_modules/          ← Instalado por npm\n│   ├── .env                   ← Tu configuración\n│   ├── package.json\n│   └── server.js\n├── frontend/\n│   ├── node_modules/          ← Instalado por npm\n│   ├── .env                   ← VITE_API_URL\n│   ├── package.json\n│   └── src/\n├── database/\n│   ├── schema.sql             ← Estructura BD\n│   └── seeds.sql              ← Datos de prueba\n├── docs/\n│   ├── ARQUITECTURA.md\n│   ├── MODELO_ER.md\n│   ├── API_ENDPOINTS.md\n│   └── MANUAL_USUARIO.md\n└── README.md\n```\n\n---\n\n## Verificación Final\n\n✅ MySQL corriendo en localhost:3306  \n✅ Backend corriendo en localhost:3001  \n✅ Frontend corriendo en localhost:5173  \n✅ Puedes iniciar sesión con admin/Admin123$  \n✅ Ves el Dashboard con datos  \n\n**Si todo está en verde, ¡tu instalación es exitosa!**\n\n---\n\n## Pasos para Siguiente Sesión\n\nLa próxima vez que quieras usar la aplicación:\n\n1.
