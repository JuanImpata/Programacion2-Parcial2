Estándares de Código\n\n### 2.1 Nomenclatura\n\n- **Archivos:** kebab-case para componentes y archivos de configuración\n  - ✅ `user-profile.jsx`, `auth-context.jsx`\n  - ❌ `UserProfile.jsx`, `AuthContext.jsx`\n\n- **Variables y Funciones:** camelCase\n  - ✅ `const userData = {}`, `function getUserData() {}`\n  - ❌ `const user_data = {}`, `function get_user_data() {}`\n\n- **Constantes:** UPPER_SNAKE_CASE\n  - ✅ `const API_BASE_URL = 'http://localhost:3001'`\n  - ❌ `const apiBaseUrl = 'http://localhost:3001'`\n\n- **Componentes React:** PascalCase\n  - ✅ `export default function UserProfile() {}`\n  - ❌ `export default function user_profile() {}`\n\n### 2.2 Estructura de Componentes React\n\n```javascript\nimport { useState, useEffect } from 'react'\nimport api from '../services/api'\n\nexport default function ComponenteName() {\n  const [state, setState] = useState(null)\n  const [error, setError] = useState(null)\n\n  useEffect(() => {\n    fetchData()\n  }, []) // Dependencias\n\n  const fetchData = async () => {\n    try {\n      const response = await api.get('/endpoint')\n      setState(response.data.data)\n    } catch (err) {\n      setError(err.message)\n    }\n  }\n\n  return (\n    <div className=\"component\">\n      {/* JSX */}\n    </div>\n  )\n}\n```\n\n### 2.3 Respuestas JSON del Backend\n\n**Éxito (200, 201):**\n```json\n{\n  \"success\": true,\n  \"data\": { /* objeto o array */ },\n  \"message\": \"Descripción de éxito\"\n}\n```\n\n**Error (4xx, 5xx):**\n```json\n{\n  \"success\": false,\n  \"data\": null,\n  \"message\": \"Descripción del error\"\n}\n```\n\n### 2.4 Manejo de Errores\n\n**En Frontend:**\n```javascript\ntry {\n  const response = await api.post('/endpoint', data)\n  // Procesar éxito\n} catch (error) {\n  console.error('Error:', error)\n  // Mostrar error al usuario\n}\n```\n\n**En Backend:**\n```javascript\nrouter.post('/endpoint', async (req, res) => {\n  try {\n    // Lógica\n    res.json({ success: true, data: result })\n  } catch (error) {\n    console.error(error)\n    res.status(500).json({ success: false, message: error.message })\n  }\n})\n```\n\n## 3. Seguridad\n\n### 3.1 Variables de Entorno\n\n**NUNCA hardcodear:**\n- ❌ `const password = 'root123'`\n- ❌ `const jwtSecret = 'secreto'`\n- ❌ `const dbHost = 'localhost'`\n\n**Siempre usar .env:**\n- ✅ `process.env.DB_PASSWORD`\n- ✅ `process.env.JWT_SECRET`\n- ✅ Archivos .env en .gitignore\n\n### 3.2 Protección de Rutas\n\n**Backend:**\n```javascript\n// Protegidas\nrouter.get('/hoteles', verifyToken, getAll)\nrouter.post('/hoteles', verifyToken, checkRole('admin'), create)\n\n// Públicas (solo auth)\nrouter.post('/auth/login', login)\nrouter.post('/auth/register', register)\n```\n\n**Frontend:**\n```javascript\nconst PrivateRoute = ({ children }) => {\n  const { isAuthenticated } = useAuth()\n  return isAuthenticated ? children : <Navigate to=\"/login\" />\n}\n```\n\n### 3.3 Hashing de Contraseñas\n\n- Usar bcrypt con mínimo 10 rounds\n- NUNCA almacenar contraseñas en texto plano\n- Comparar siempre con bcrypt.compare()\n\n```javascript\n// Correcto\nconst hash = await bcrypt.hash(password, 10)\nconst valid = await bcrypt.compare(password, hash)\n\n// Incorrecto\nconst hash = password // ❌\nconst valid = password === hash // ❌\n```\n\n## 4. Base de Datos\n\n### 4.1 Convenciones SQL\n\n- **Nombres de tablas:** minúsculas, plural si es lógico\n  - ✅ `usuarios`, `hoteles`, `reservas`\n  - ❌ `Usuario`, `Hotel`, `Reserva`\n\n- **Nombres de columnas:** minúsculas, snake_case\n  - ✅ `cod_hotel`, `fecha_inicio`, `tipo_IVA`\n  - ❌ `codHotel`, `fechaInicio`, `tipoIva`\n\n- **Claves primarias:** `cod_<tabla>` o `id`\n- **Claves foráneas:** mismo nombre que la PK de la tabla referenciada\n\n### 4.2 Normalización\n\n- Todas las tablas deben estar en 3NF (Tercera Forma Normal)\n- No repetir datos entre tablas\n- Usar claves foráneas para integridad referencial\n\n### 4.3 Ejemplo de Tabla\n\n```sql\nCREATE TABLE usuarios (\n    id INT AUTO_INCREMENT PRIMARY KEY,\n    usuario VARCHAR(50) NOT NULL UNIQUE,\n    password VARCHAR(255) NOT NULL,\n    rol ENUM('admin','usuario','moderador') NOT NULL DEFAULT 'usuario',\n    creado_en TIMESTAMP DEFAULT CURRENT_TIMESTAMP\n);\n```\n\n## 5.
