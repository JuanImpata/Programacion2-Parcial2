# 📚 Índice Completo de Documentación - Hotel App\n\n## Bienvenida\n\nBienvenido a la documentación completa del proyecto **Hotel App** desarrollado para el curso de Programación II en la Universidad Libre Seccional Pereira.\n\nEste índice te ayudará a navegar por toda la documentación disponible.\n\n---\n\n## 📋 Documentación General\n\n### 1. [README.md](../README.md)\n**Para:** Principiantes y resumen rápido\n\n- Descripción general del proyecto\n- Stack tecnológico utilizado\n- Usuarios de prueba\n- Enlaces a documentación\n\n**Tiempo de lectura:** 5-10 minutos\n\n---\n\n## 🚀 Guías de Inicio\n\n### 2. [GUIA_INSTALACION.md](GUIA_INSTALACION.md)\n**Para:** Configurar el proyecto por primera vez\n\n- Verificación de requisitos\n- Instalación paso a paso\n- Configuración de base de datos\n- Solución de problemas comunes\n- Verificación final\n\n**Cuándo usarlo:** Antes de ejecutar el proyecto\n**Tiempo de lectura:** 20-30 minutos\n\n### 3. [MANUAL_USUARIO.md](MANUAL_USUARIO.md)\n**Para:** Usar la aplicación día a día\n\n- Cómo acceder\n- Navegación por secciones\n- Crear, editar y eliminar datos\n- Controles por rol de usuario\n- Búsqueda y filtrado\n- Tips y buenas prácticas\n- Solución de problemas de usuario\n\n**Cuándo usarlo:** Mientras usas la aplicación\n**Tiempo de lectura:** 15-20 minutos\n\n---\n\n## 🏗️ Documentación Técnica\n\n### 4. [ARQUITECTURA.md](ARQUITECTURA.md)\n**Para:** Entender la estructura técnica del proyecto\n\n- Diagrama de arquitectura de tres capas\n- Descripción de componentes\n- Flujo de comunicación entre capas\n- Medidas de seguridad\n- Stack tecnológico por capa\n- Diagrama de componentes\n\n**Audiencia:** Desarrolladores, instructores\n**Cuándo usarlo:** Para comprender la estructura general\n**Tiempo de lectura:** 15-20 minutos\n\n### 5. [MODELO_ER.md](MODELO_ER.md)\n**Para:** Comprender la estructura de la base de datos\n\n- Diagrama Entidad-Relación\n- Descripción detallada de cada tabla\n- Tipos de datos y restricciones\n- Relaciones entre entidades\n- Cardinalidad\n- Verificación de normalización 3NF\n\n**Audiencia:** Desarrolladores backend, DBAs\n**Cuándo usarlo:** Para entender la BD o hacer cambios\n**Tiempo de lectura:** 15-20 minutos\n\n### 6. [API_ENDPOINTS.md](API_ENDPOINTS.md)\n**Para:** Integración y testing de endpoints\n\n- Base URL de la API\n- Autenticación y headers\n- Completa referencia de todos los endpoints\n- Ejemplos de request/response\n- Códigos de estado HTTP\n- Restricciones por rol\n\n**Audiencia:** Desarrolladores frontend/backend, testers\n**Cuándo usarlo:** Para hacer llamadas a la API\n**Tiempo de lectura:** 20-30 minutos\n\n### 7. [ESTANDARES_TECNICOS.md](ESTANDARES_TECNICOS.md)\n**Para:** Mantener consistencia en el código\n\n- Estructura de carpetas requerida\n- Nomenclatura de archivos y variables\n- Estructura de componentes React\n- Formato de respuestas JSON\n- Estándares de seguridad\n- Convenciones SQL\n- Prácticas de Git\n- Checklist previo a entregar\n\n**Audiencia:** Desarrolladores, estudiantes\n**Cuándo usarlo:** Al escribir código nuevo\n**Tiempo de lectura:** 25-35 minutos\n\n---\n\n## 🎯 Flujos de Trabajo Recomendados\n\n### Para Instalar por Primera Vez\n1.
